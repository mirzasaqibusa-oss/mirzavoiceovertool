### ⚙️ Setup (one-time, for the owner)
1. Apne **GitHub repo** mein `MirzaSaqib_Kaggle.ipynb` upload karo (wahi repo jahan Colab wala hai).
2. Upar wale 2 jagah **`USERNAME/REPO`** ko apne asli GitHub username aur repo ke naam se replace karo.
   - Example: agar repo `https://github.com/mirzasaqib/mirza-tools` hai, to link banega:
     `https://kaggle.com/kernels/welcome?src=https://github.com/mirzasaqib/mirza-tools/blob/main/MirzaSaqib_Kaggle.ipynb`
   - Agar branch `main` ki jaga `master` hai to `main` ko `master` kar dena.
3. Ye snippet apne repo ke **README.md** mein paste kar do — badge apne aap clickable ban jayega.
4. Users ko bas yehi ek link/badge bhejo — wo click karke tool chala lenge.
